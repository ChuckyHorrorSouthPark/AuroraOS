## Troubleshooting

### Application Won't Open

**Solution**:
1. Force quit: Cmd+Option+Esc
2. Restart application
3. Check System Settings → Privacy & Security
4. Reinstall if persistent

### Slow Performance

**Solution**:
1. Activity Monitor → CPU/Memory tabs
2. Identify heavy processes
3. Close unnecessary applications
4. Restart computer
5. Upgrade RAM if needed

### Wi-Fi Connection Issues

**Solution**:
1. Forget network (Wi-Fi settings)
2. Reconnect to network
3. Restart Wi-Fi router
4. Check router placement
5. Update drivers

### Battery Draining Quickly

**Solution**:
1. Activity Monitor → Energy tab
2. Identify power-hungry apps
3. Settings → Energy Saver
4. Reduce screen brightness
5. Disable background apps

### File Not Found

**Solution**:
1. Open Pathfinder
2. Use search (Cmd+F)
3. Search file by name
4. Check Trash if recently deleted
5. Use Time Machine if deleted

**Delete Unused Applications**:
1. Applications folder in Pathfinder
2. Drag unused apps to Trash
3. Empty Trash

**Remove Browser Cache**:
1. Open browser preferences
2. Privacy section
3. Clear browsing data
4. Set frequency (weekly, monthly)

**Manage Disk Space**:
1. Settings → Storage
2. Review large files
3. Delete old downloads
4. Archive old files

**Check for Updates**:

**Security Patches**:
- Applied monthly
